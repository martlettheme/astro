# Grammar 0.3 and Astro support

Canonical source: https://github.com/martlettheme/npm/tree/bbd30eb29daddfb8f706693d5afa7858bed97d8e

The [coverage ledger](https://github.com/martlettheme/npm/blob/bbd30eb29daddfb8f706693d5afa7858bed97d8e/docs/coverage.md), [validated form](https://github.com/martlettheme/npm/blob/bbd30eb29daddfb8f706693d5afa7858bed97d8e/docs/patterns/forms.md), and [query/results](https://github.com/martlettheme/npm/blob/bbd30eb29daddfb8f706693d5afa7858bed97d8e/docs/patterns/query-results.md) specify shared composition and interaction obligations. The interactive references use React's existing exports.

Astro 1.2.0 supplies its documented layout, reading, contents and footer components. Native HTML can express the form labels, groups, errors, table and checkbox structure; host scripts must implement validation, query transport, state, focus transitions and cancellation. There is no Astro Form, QueryResults or selection controller in this candidate. Shared grammar does not create a shared event/prop API.

The source-profile import remains opt-in. Existing package defaults and APIs are unchanged. Grammar 0.3, full dark mode and the new application contracts remain experimental. Compact density, manual assistive technology, localization/RTL, dashboard breadth and sustained consumer use remain open.
